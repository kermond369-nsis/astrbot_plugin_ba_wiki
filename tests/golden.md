新会话照这张表跑一遍，就能判断重构有没有破坏行为。能自动化的部分都在
`tests/selfcheck.py` 里（103 项断言），本表是人肉核对用的对照单。

判定标准：**是否命中同一个角色** + **显示名是否合规** + **该给候选的给候选**。

```bash
python tests/selfcheck.py
```
